# EST Practice – notes for teachers

**Assets used:**

- **Megatrends - Summary of Info for EST prep.pdf** – Course content. The game’s EST Practice questions are based on this (Impactful Technology only for now). Defines megatrends, types (economic power shifts, demographic shifts, impactful technology, climate change), and impact on work environments, types of employment, and emerging/declining jobs.
- **GTCEM EST Question Decoder.pdf** – How to answer EST questions: **VTCS** (Verb, Topic, Context, Structure), command verbs (Identify, Outline, Describe, Explain, Discuss, Compare, Analyse), mark allocation, sentence starters, and “Because → For example → As a result” for stronger answers.

The **results screen** after EST Practice now shows a short decoder tip based on the GTCEM decoder. To edit it: in `main.js` search for `est-decoder-tip`.

**Points:** 10–15 per question (total 65). Correct answers add to the score; wrong answers show “Key points” feedback aligned to the EST prep content.
